# Trastornos Varios y TID

Sitio educativo estático para GitHub Pages.

## Archivos
- `index.html` — portada
- `depresion.html` — sección depresión
- `bipolaridad.html` — sección bipolaridad
- `tlp.html` — sección TLP
- `tid.html` — sección extensa TID
- `mitos.html` — mitos y realidades
- `recursos.html` — fuentes y recursos
- `css/style.css` — estilos generales
- `css/pages.css` — estilos de páginas
- `css/tid.css` — identidad visual especial del TID
- `js/main.js` — menú y barra de progreso
- `js/interactions.js` — animaciones y acordeón

## Publicar
1. Reemplaza los archivos de tu repositorio por estos.
2. Conserva la estructura de carpetas.
3. En GitHub: Settings → Pages → selecciona la rama que usas para publicar.
4. Espera a que GitHub Pages vuelva a desplegar el sitio.

No se necesitan frameworks ni instalación de dependencias.
